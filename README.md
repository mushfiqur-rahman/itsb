# IT Support Bee - Lightweight WordPress Classic Theme

A lightweight, fast, and SEO-friendly WordPress Classic Theme built for IT agencies, MSPs, and technology service providers.

This project is a custom conversion of a Tailwind CSS HTML template into a traditional WordPress Classic Theme with minimal dependencies and excellent performance.

## Features

- ⚡ Lightweight and fast loading
- 🎨 Custom WordPress Classic Theme
- 📱 Fully responsive design
- 🔍 SEO-friendly structure
- ♿ Accessibility-focused design
- 🚀 Performance optimized
- 📝 Blog support
- 📰 Single post template
- 💼 Services pages
- 📞 Contact page
- 🔧 Easy to customize for developers
- 📦 No page builder required

## Installation

1. Download or clone this repository.

```bash
git clone https://github.com/mushfiqur-rahman/itsb.git
```

2. Copy the theme into your WordPress installation.

```text
wp-content/themes/itsb/
```

3. Login to your WordPress Dashboard.

4. Navigate to

```
Appearance → Themes
```

5. Activate **IT Support Bee**.

---

## Development

This theme is intended to be developed locally.

Recommended workflow:

- Clone the repository
- Develop on a local WordPress environment
- Test all pages
- Push changes to GitHub
- Deploy only the updated theme files

> **Note**
>
> Design changes should be made in your local development environment. There is currently no theme options panel for editing layouts from the WordPress dashboard.
